# 12. Ohjelman analyysi

{: .code-title }
collatz.c
```c
#include <stdio.h>

#define N 10000000

int collatz(long n) {
    int steps = 1;
    while (n != 1) {
        steps++;
        if (n % 2 == 0) {
            n = n / 2;
        } else {
            n = 3 * n + 1;
        }
    }
    return steps;
}

int main(void) {
    long total = 0;
    for (int i = 1; i <= N; i++) {
        total += collatz(i);
    }
    printf("%ld\n", total);
}
```

### Koodin yleiskuva

```nasm
	endbr64
	pushq	%rbp
	movq	%rsp, %rbp
```

```nasm
	leave
	ret
```

- varaa pinosta muistia 16 tavua
- muuttuja total kohdassa -8
- muuttuja i kohdassa -12
- miksi cltq-komento?
- miksi add eikä inc?
- .LC0(%rip) viittaus
- printf@PLT

### Collatz-jonon laskenta

- ei varaa muistia erikseen pinosta (red zone)
- muuttuja steps kohdassa -8
- muuttuja n kohdassa -24

Parillisuustarkastus:

```nasm
	andl	$1, %eax
	testq	%rax, %rax
	jne	.L3
```

Jako kahdella:

```nasm
	movq	%rax, %rdx
	shrq	$63, %rdx
	addq	%rdx, %rax
	sarq	%rax
```

3*n+1:

```nasm
	movq	%rdx, %rax
	addq	%rax, %rax
	addq	%rdx, %rax
	addq	$1, %rax
```
