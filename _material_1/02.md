# 2. Tiedon käsittely

## Tieto bitteinä

Tiedon käsittelyn perusyksiköt ovat _bitti_ (_bit_) ja _tavu_ (_byte_).

- Bitti on 0 tai 1, ja sen avulla voidaan esittää kaksi eri vaihtoehtoa.

- Tavu on (yleensä) 8 bitin yhdistelmä. Esimerkiksi 00100101 ja 11101101 ovat tavuja. Tavun avulla voidaan esittää 256 (2<sup>8</sup>) eri vaihtoehtoa.

C-kielessä lukuarvot esitetään yhden tai useamman tavun yhdistelmänä. Pienin tietotyyppi on `char`, jonka kokona on yksi tavu.

Tavallinen kokonaislukua esittävä tietotyyppi `int` on usein kooltaan 4 tavua, eli se muodostuu 32 bitistä. C-standardi ei kuitenkaan määrittele tarkasti eri tietotyyppien kokoa, vaan tämä voi vaihdella ympäristön mukaan. Tietotyypistä `int` standardi määrittelee vain, että sen koon tulee olla _vähintään_ 2 tavua.

Operaattorin `sizeof` avulla voidaan selvittää tietyn tietotyypin koko käytetyssä ympäristössä. Operaattori antaa tietotyypin koon tavuina. Esimerkiksi seuraava koodi näyttää tietotyyppien `char` ja `int` koot:

```c
printf("%zu\n", sizeof(char));
printf("%zu\n", sizeof(int));
```

Koodin tyypillinen tulostus on:

```
1
4
```

Operaattori `sizeof` palauttaa koon `size_t`-tyyppisenä kokonaislukuna, jota vastaa `printf`-funktiossa käytetty muotoilu `%zu`.

### Kokonaisluvun esitystapa

Tavallinen tapa esittää kokonaisluku bittimuodossa on esittää se binäärilukuna eli lukujärjestelmässä, jonka kantaluku on 2.

Esimerkiksi luku 123 on binäärilukuna 1111011, koska luku voidaan esittää seuraavasti 2:n potenssien summana:

<center>
123 = 2<sup>6</sup> + 2<sup>5</sup> + 2<sup>4</sup> + 2<sup>3</sup> + 2<sup>1</sup> + 2<sup>0</sup>
</center>

Kun luku 123 tallennetaan `int`-muuttujaan koodilla

```c
int x = 123;
```

niin se tallennetaan tyypillisesti muistiin 4-tavuisena binäärilukuna seuraavasti:

<center>
00000000 00000000 00000000 01111011
</center>

Tässä tapauksessa luku on sen verran pieni, että se mahtuu yhteen tavuun, jolloin kolme muuta tavua ovat pelkkää nollaa.

### Kahden komplementti

Äsken kuvatulla tavalla pystyy esittämään hyvin nollan ja positiiviset kokonaisluvut, mutta kokonaisluku voi olla myös negatiivinen.

Tavallinen tapa käsitellä negatiivisia kokonaislukuja on sopia, että luvun bittiesityksen ensimmäinen bitti ilmaisee, onko luku positiivinen (0) vain negatiivinen (1). Yleensä käytetään _kahden komplementtia_ (_two's complement_), jossa luvun etumerkkiä voidaan vaihtaa kääntämällä kaikki bitit ja lisäämällä tulokseen yksi.

Esimerkiksi luku –123 esitetään 4-tavuisena binäärilukuna seuraavasti:

<center>
11111111 11111111 11111111 10000101
</center>

### Lukualueet

C-kielessä on käytettävissä kahdenlaisia kokonaislukuja: _etumerkilliset_ (_signed_) ja _etumerkittömät_ (_unsigned_) kokonaisluvut.

Etumerkillinen luku voi olla positiivinen, negatiivinen tai nolla. Etumerkitön luku voi puolestaan olla vain positiivinen tai nolla. Etumerkki vaikuttaa siihen, miten suuria lukuja voidaan esittää, koska etumerkki vie luvussa yhden bitin tilaa.

Oletuksena esimerkiksi tyyppi `int` on etumerkillinen, eli siihen voidaan tallentaa myös negatiivisia lukuja. Tyyppi `unsigned int` sen sijaan on etumerkitön, eli sen kuvaama luku on aina vähintään nolla.

<div class="note" markdown="1">
C-kielessä on usein monta vaihtoehtoista nimeä samalle tietotyypille. Esimerkiksi `int` tarkoittaa samaa kuin `signed int` tai pelkkä `signed`. Vastaavasti `unsigned int` tarkoittaa samaa kuin `unsigned`.
</div>

Tavallinen tyypin `int` lukualue on –2<sup>31</sup>...2<sup>31</sup>–1. Tässä positiivisen luvun suuruuden yläraja on yksi pienempi kuin negatiivisella luvulla, koska etumerkkiä 0 käytetään sekä positiivisen luvun että nollan esittämiseen.

Tavallinen tyypin `unsigned int` lukualue on 0...2<sup>32</sup>–1. Siis luvun yläraja on noin kaksinkertainen, mutta ei ole mahdollista esittää negatiivista lukua.

### Ylivuoto

Mitä tapahtuu, jos käytetty tietotyyppi on liian pieni lukua varten? Seuraava koodi sijoittaa muuttujaan `x` luvun 2<sup>31</sup>–1, joka on käytetyssä ympäristössä `int`-tyypin lukualueen suurin luku. Tämän jälkeen koodi kasvattaa muuttujan arvoa yhdellä ja tulostaa muuttujan uuden arvon.

```c
int x = 2147483647; // 2^31-1
printf("%d\n", x);

x++;
printf("%d\n", x);
```

Koodin tulos on seuraava:

```
2147483647
-2147483648
```

Tässä tapahtuu _ylivuoto_ (_overflow_), eli luku pyörähtää ympäri ja siitä tulee lukualueen pienin luku. Huomaa, että ylivuoto ei aiheuta virhettä eikä siitä tule ilmoitusta ohjelman suorituksen aikana. Ohjelma toimii sinänsä, mutta ylivuodon takia tulos voi erota halutusta tuloksesta.

Vastaavasti ylivuoto tapahtuu toiseen suuntaan, jos muuttujassa on lukualueen pienin luku ja muuttujan arvoa vähennetään:

```c
int x = -2147483648; // -2^31
printf("%d\n", x);

x--;
printf("%d\n", x);
```

Koodin tulos on seuraava:

```
-2147483648
2147483647
```

<div class="note" markdown="1">
C:n tyyppi `int` ja Pythonin tyyppi `int` ovat siis hyvin erilaisia. C:ssä tyypin `int` koko on rajoitettu (usein 4 tavua), minkä takia se kattaa vain tietyn lukualueen. Pythonissa tyypin `int` avulla voi esittää periaatteessa miten tahansa suuren kokonaisluvun, kuten luvun 123<sup>123</sup>, jossa on 258 numeroa:

```python
x = 123**123
```

C:ssä tyypin `int` käyttäminen on hyvin tehokasta, koska lukujen koko on rajattu ja tietokoneen prosessorissa on valmiit konekieliset komennot tällaisten lukujen käsittelemiseen.

Pythonissa tilanne on toinen, eikä suuria lukuja voi käsitellä suoraan tietokoneen laitteiston tasolla. Vaikka ohjelmoijan on helppoa käyttää kokonaislukuja, tämän taustalla Pythonin suoritusympäristössä on monimutkaista koodia, mikä hidastaa lukujen käsittelemistä.
</div>

## Bittioperaatiot

Luvun bittejä voidaan käsitellä tehokkaasti bittioperaatioiden avulla.

- Operaatio `a & b` (and) tuottaa luvun, jossa on ykkösbitti niissä kohdissa, joissa on ykkösbitti sekä luvussa `a` että `b`.

- Operaatio `a | b` (or) tuottaa luvun, jossa on ykkösbitti niissä kohdissa, joissa on ykkösbitti ainakin toisessa luvuista `a` ja `b`.

- Operaatio `a ^ b` (xor) tuottaa luvun, jossa on ykkösbitti niissä kohdissa, joissa on ykkösbitti tarkalleen yhdessä luvuista `a` ja `b`.

- Operaatio `~x` (not) tuottaa luvun, jossa jokainen bitti on käänteinen lukuun `x` verrattuna.

- Vasen bittisiirto `x << k` siirtää luvun bittejä `k` askelta vasemmalle.

- Oikea bittisiirto `x >> k` siirtää luvun bittejä `k` askelta oikealle.

### Esimerkkejä

Seuraava koodi esittelee and-, or- ja xor-operaatioita:

```c
int a = 25;
int b = 42;

printf("%d\n", a & b); // 8
printf("%d\n", a | b); // 59
printf("%d\n", a ^ b); // 51
```

Bittimuodossa operaatiot näyttävät seuraavilta:

```
    25 = 00011001        25 = 00011001        25 = 00011001
    42 = 00101010        42 = 00101010        42 = 00101010
and -------------     or -------------    xor -------------
     8 = 00001000        59 = 00111011        51 = 00110011
```

Yllä on esitetty vain luvun viimeisen tavun sisältö bittimuodossa, koska kaikissa muissa tavuissa kaikki bitit ovat nollia.

Operaatio not vaikuttaa lukuun näin:

```c
int x = 123;

printf("%d\n", ~x); // -124
```

Tulos on odotusten mukainen, koska kahden komplementissa negatiivinen luku saadaan kääntämällä kaikki bitit ja lisäämällä tulokseen yksi. Tässä vain bitit käännetään, joten tulos on yhden pienempi kuin negatiivinen luku.

Bittimuodossa operaatio näyttää seuraavalta:

```
     123 = 00000000 00000000 00000000 01111011
not ------------------------------------------
    -124 = 11111111 11111111 11111111 10000100
```

Seuraava koodi esittelee bittisiirtoja:

```c
int x = 6;

printf("%d\n", x << 1); // 12
printf("%d\n", x << 2); // 24

printf("%d\n", x >> 1); // 3
printf("%d\n", x >> 2); // 1
```

Vasen bittisiirto `k` askelta vastaa luvun kertomista 2<sup>`k`</sup>:lla ja oikea bittisiirto `k` askelta vastaa luvun jakamista 2<sup>`k`</sup>:lla (pyöristys alaspäin kokonaisluvuksi).

Bittimuodossa operaatiot näyttävät tältä:


```
      6 = 00000110          6 = 00000110
<< 1 -------------    << 2 -------------
     12 = 00001100         24 = 00011000


      6 = 00000110          6 = 00000001
>> 1 -------------    >> 2 -------------
      3 = 00000011          1 = 00000001
```

### Bittiesitys koodilla

Seuraava koodi tulostaa muuttujassa `x` olevan luvun bittiesityksen:

```c
int x = 123;

for (int k = 31; k >= 0; k--) {
    if (x & (1 << k)) {
        printf("1");
    } else {
        printf("0");
    }
}
printf("\n");
```

Koodin tulostus on seuraava:

```
00000000000000000000000001111011
```

Koodi käy läpi kaikki luvun bitit ja tarkastaa jokaisen bitin kohdalla, onko bitti 1 vai 0. Koska kyseessä on `int`-luku, koodi olettaa, että luku on 32-bittinen.

Koodissa on käytössä bittimaski, joka muodostetaan bittisiirrolla `1 << k`. Tässä bittimaskissa on tasan yksi ykkösbitti ja kaikki muut bitit ovat nollia. Jos operaatio `x & (1 << k)` tuottaa positiivisen tuloksen, tiedetään, että luvussa `x` on ykkösbitti samassa kohdassa kuin luvussa `1 << k`. Muussa tapauksessa luvussa `x` on nollabitti kyseisessä kohdassa.

Esimerkiksi kun `k = 3`, luvun `x` ja bittimaskin `1 << k` and-operaatio näyttää tältä:

```
         x = 00000000000000000000000001111011
    1 << k = 00000000000000000000000000001000
and -----------------------------------------
             00000000000000000000000000001000
```

Tulos on positiivinen, joten luvussa `x` on ykkösbitti kyseisessä kohdassa.

## Muuttuja muistissa

Tarkastellaan seuraavaa C-koodia, joka määrittelee muuttujan:

```c
int x = 123456;
```

Koodin suorituksen aikana muuttujan arvo tulee tallentaa jollakin tavalla tietokoneen muistiin, jotta muuttujaa pystyy käyttämään.

Hyvä tapa ymmärtää tietokoneen muistia on ajatella, että muistissa on peräkkäin sarja tavuja, joista jokaisella on tietty muistiosoite. _Tavu_ (_byte_) on muistin käsittelyn perusyksikkö, joka muodostuu yleensä 8 bitistä.

Muistinkäsittelyn kannalta olennaiset asiat ovat, missä muistiosoitteessa muuttujan sisältö on ja montako tavua tilaa se vie. C-kielessä muuttujan muistiosoite voidaan selvittää `&`-operaattorilla seuraavaan tapaan:

```c
printf("%p\n", &x);
```

Koodin tulostus voisi olla esimerkiksi seuraava:

```
0x7ffe9c985da0
```

Tämä tarkoittaa, että muuttuja `x` on muistissa osoitteessa `0x7ffe9c985da0`.

Huomaa, että muuttujan sijainti muistissa yleensä muuttuu jokaisella ohjelman suorituskerralla. Jos kokeilet suorittaa yllä olevan koodin itse, saat lähes varmasti eri tuloksen kuin esimerkissä.

C-kielessä operaattori `sizeof` kertoo, montako tavua tietotyyppi vie tilaa. Esimerkiksi seuraava koodi tulostaa `int`-tyypin koon tavuina:

```c
printf("%zu\n", sizeof(int));
```

Modernissa Linux-ympäristössä tämän koodin tulostus voisi olla:

```
4
```

Tämä tarkoittaa, että `int`-tyyppinen muuttuja vie 4 tavua tilaa muistissa.

Nyt meillä on alustava käsitys siitä, miten muuttuja `x` on tallennettu muistiin:

```
0x7ffe9c985d9e
0x7ffe9c985d9f
0x7ffe9c985da0 | x
0x7ffe9c985da1 |
0x7ffe9c985da2 |
0x7ffe9c985da3 |
0x7ffe9c985da4
0x7ffe9c985da5
```

## Osoittimet

Keskeinen käsite C-ohjelmoinnissa on _osoitin_ (_pointer_), jonka kautta voidaan käsitellä muistin sisältöä muistiosoitteen perusteella.

Esimerkiksi seuraava koodi määrittelee osoittimen `p`, joka osoittaa `int`-tyyppiseen arvoon muistissa:

```c
int *p;
```

Osoitin määritellään siis muuten samalla tavalla kuin tavallinen muuttuja, mutta ennen muuttujan nimeä tulee merkki `*`.

Osoittimen määrittelyn jälkeen sen arvoksi voidaan asettaa jokin muistiosoite, kuten jonkin muuttujan osoite muistissa. Esimerkiksi seuraava koodi asettaa osoittimen `p` arvoksi muuttujan `x` muistiosoitteen:

```c
p = &x;
```

Syntaksilla `*p` voidaan viitata muistissa olevaan arvoon, joka on osoitteessa `p`. Esimerkiksi jos `p` sisältää muuttujan `x` osoitteen, `*p` viittaa muistissa olevaan muuttujan `x` arvoon.

Seuraava koodi näyttää tarkemmin, miten osoitinta voidaan käyttää. Koodi määrittelee muuttujan `x` ja osoittimen `p`, joka viittaa muuttujaan `x`. Tämän jälkeen koodi muuttaa muuttujan `x` arvoa osoittimen `p` kautta.

```c
int x = 5;
int *p = &x;

printf("%p\n", p);
printf("%d\n", *p);

*p = 8;
printf("%d\n", *p);
printf("%d\n", x);
```

Koodin tulostus on seuraava:

```
0x7ffe9c985da0
5
8
8
```

## Muistin lukeminen

Katsotaan seuraavaksi, miten voimme lukea muistin sisältöä tavu kerrallaan osoittimen avulla.

Tietotyyppi `char` on määritelty niin, että se vastaa yhtä tavua (eli `sizeof(char)` antaa tuloksen 1). Tämän tietotyypin avulla voimme lukea yksittäisiä tavuja muistista ja tutkia tarkemmin muistin sisältöä.

Seuraava koodi määrittelee `char`-osoittimen `p` ja sijoittaa siihen muuttujan `x` muistiosoitteen. Sen jälkeen koodi tulostaa näkyviin neljä tavua muuttujan `x` muistiosoitteesta alkaen:

```c
int x = 123456;
unsigned char *p;
p = (unsigned char*)&x;
printf("%d\n", *p);
printf("%d\n", *(p + 1));
printf("%d\n", *(p + 2));
printf("%d\n", *(p + 3));
```

Tässä osoittimen tyyppinä on `unsigned char`, jotta voimme lukea osoittimen kautta etumerkittömiä tavuja muistista. Käytännössä jokainen muistissa oleva tavu on kokonaisluku välillä 0–255.

Koska `&x` palauttaa `int`-osoittimen, koodissa on tyyppimuunnos `(unsigned char*)`, joka muuttaa osoittimen `unsigned char` -tyyppiseksi.

Tämän jälkeen voimme lukea muistista muuttujan `x` sisällön tavu kerrallaan. Koska kyseessä on `int`-muuttuja, siinä on yhteensä 4 tavua. Ensimmäinen tavu on muistissa kohdassa `p`, toinen tavu on kohdassa `p + 1` jne.

Tässä on vielä hieman tyylikkäämpi toteutus `for`-silmukan avulla:

```c
int x = 123456;
unsigned char *p;
p = (unsigned char*)&x;
for (int i = 0; i < 4; i++) {
    printf("%d\n", *(p + i));
}
```

Kun suoritamme koodin, saamme seuraavan tuloksen:

```
64
226
1
0
```

Luku 123456 on tallennettu siis muistiin neljänä tavuna 64, 226, 1 ja 0. Käytössä on little endian -muoto, mikä tarkoittaa, että tavujen järjestys on käänteinen:

<center>
2<sup>24</sup> &middot; 0 + 2<sup>16</sup> &middot; 1 + 2<sup>8</sup> &middot; 226 + 2<sup>0</sup> &middot; 64 = 123456
</center>

C-kielen tavallinen tietotyyppi on `int`, joka sisältää kokonaisluvun. Toisin kuin esimerkiksi Pythonissa, C-kielen `int`-tyypin lukualue on rajoitettu eli luvun suuruudelle on tietty alaraja ja yläraja. Kun koodissa on `int`-tyyppinen muuttuja, sen sisältö vie aina kiinteän määrän tilaa muistissa.

C-standardi ei kuitenkaan määrittele tarkasti `int`-tyypin kokoa, vaan tämä riippuu käytetystä ympäristöstä. Seuraava koodi näyttää `int`-tyypin koon tavuina sekä luvun alarajan ja ylärajan:

```c
#include <stdio.h>
#include <limits.h>

int main(void) {
    printf("%zu\n", sizeof(int));
    printf("%d %d\n", INT_MIN, INT_MAX);
    return 0;
}
```

Tässä `sizeof`-operaattori antaa tietotyypin koon tavuina ja tiedostossa `limits.h` olevat vakiot `INT_MIN` ja `INT_MAX` antavat `int`-tyypin alarajan ja ylärajan.

Tavallinen tulos modernissa Linux-ympäristössä on:

```
4
-2147483648 2147483647
```

Tämä tarkoittaa, että `int`-tyypin koko on 4 tavua, pienin mahdollinen luku on `-2147483648` (–2<sup>31</sup>) ja suurin mahdollinen luku on `2147483647` (2<sup>31</sup>–1).

<div class="note" markdown="1">
_Tavu_ (_byte_) muodostuu yleensä 8 bitistä ja se on pienin tiedon yksikkö, johon voidaan osoittaa tietokoneen muistissa.

Kun `int`-tyypin koko on 4 tavua ja jokainen tavu muodostuu 8 bitistä, tietotyypin koko on 32 bittiä eli sen avulla voidaan esittää 2<sup>32</sup> eri kokonaislukua. Tavallinen ratkaisu on määritellä lukuväli niin, että pienin mahdollinen luku on –2<sup>31</sup> ja suurin mahdollinen luku on 2<sup>31</sup>–1.

Palaamme myöhemmin tarkemmin siihen, mitä tarkoittaa muistin osoittaminen tietokoneessa sekä miksi lukuväli on määritelty yllä olevalla tavalla.

## Tietotyypit

### Kokonaisluvut

C-kielen kokonaislukutyypit ovat:

Tietotyyppi | Koko vähintään | Tavallinen koko
--- | ---
`char` | 8 bittiä | 8 bittiä
`short` | 16 bittiä | 16 bittiä
`int` | 16 bittiä | 32 bittiä
`long` | 32 bittiä | 64 bittiä
`long long` | 64 bittiä | 64 bittiä

Yllä olevassa taulukossa "koko vähintään" on C-standardin määrittelemä pienin mahdollinen tietotyypin koko ja "tavallinen koko" on tyypillinen tietotyypin koko esimerkiksi modernissa Linux-ympäristössä.

Pienin tietotyyppi on `char`, joka vastaa yhtä tavua tai merkkiä. Määritelmän mukaan `char`-tyypin koko on 1 tavu eli `sizeof(char)` antaa tuloksen 1. Kaikkien muiden tietotyyppien koot ovat tämän koon moninkertoja.

Muut kokonaislukutyypit ovat pienimmästä suurimpaan `short`, `int`, `long`, `long long`. Näistä tyypeistä voi olettaa, että jokainen tyyppi on vähintään yhtä suuri kuin edellinen tyyppi listassa.

Tietotyypin lukualueeseen vaikuttaa koon lisäksi, onko tietotyyppi etumerkillinen (`signed`) vai etumerkitön (`unsigned`). Esimerkiksi tyyppi `int` (pidemmin `signed int`) on etumerkillinen ja se voi yleensä sisältää luvun väliltä –2<sup>31</sup> ja 2<sup>31</sup>–1. Tyyppi `unsigned int` on puolestaan etumerkitön ja se voi yleensä sisältää luvun väliltä 0 ja 2<sup>32</sup>–1.

<div class="note" markdown="1">
Monilla C-kielen tietotyypeillä on useita vaihtoehtoisia nimiä. Esimerkiksi tyyppiin `int` voidaan viitata myös nimillä `signed int` ja `signed`.

Tietotyypit `short`, `long` ja `long long` ovat tyypin `int` alityyppejä ja niihin voidaan viitata myös nimillä `short int`, `long int` ja `long long int`.

Tästä seuraa, että tyyppiin `long` voidaan viitata kaikilla seuraavilla nimillä:

- `long`
- `long int`
- `signed long`
- `signed long int`
</div>

### Liukuluvut

C-kielen liukulukutyypit ovat pienimmästä suurimpaan `float`, `double` ja `long double`. Kuten kokonaislukutyypeissä, C-standardi ei määrittele tarkasti tyyppien kokoa mutta jokainen tyyppi on vähintään yhtä suuri kuin edellinen tyyppi listassa.

## Luvut muistissa

Ohjelman suorituksen aikana jokaisen muuttujan sisältö on tietyssä kohdassa tietokoneen muistissa. Muuttujan muistiosoite voidaan selvittää operaattorilla `&` seuraavaan tapaan:

```c
int number = 5;
printf("%d\n", number);
printf("%p\n", &number);
```

Tässä ensimmäinen `printf`-komento tulostaa muuttujan _sisällön_ ja toinen komento tulostaa muuttujan _muistiosoitteen_. Koodin tulos on seuraavan tapainen:

```
5
0x7fff46f65aa4
```

Tämä tarkoittaa, että muuttujan `a` muistiosoite ohjelman suorituksen aikana oli `0x7fff46f65aa4`. Huomaa, että muistiosoite riippuu siitä, miten käyttöjärjestelmä varaa muistia ohjelmalle, ja se yleensä vaihtelee ohjelman eri suorituskerroilla.

Seuraavassa koodissa muuttuja `pointer` on _osoitin_ (_pointer_), johon sijoitetaan muuttujan `number` muistiosoite. Koodi muuttaa osoittimen kautta muuttujan `number` sisältöä.

```c
int number = 5;
int *pointer;
pointer = &number;

printf("%p\n", pointer);
printf("%d\n", *pointer);

*pointer = 8;
printf("%d\n", *pointer);
printf("%d\n", number);
```

Koodin tulostus on seuraava:

```
0x7ffd43b28b54
5
8
8
```

Huomaa, että merkkiä `*` käytetään tässä kahdella vähän eri tavalla:

- Muuttujan määrittelyssä `int *pointer` tarkoittaa, että `pointer` on osoitin, joka viittaa `int`-tyyppiseen arvoon muistissa.
- Myöhemmin `pointer` antaa muuttujan `number` osoitteen ja `*pointer` viittaa muuttujaan `number` osoittimen kautta.

Koska `pointer` sisältää muuttujan `number` osoitteen, rivi `*pointer = 8;` muuttaa muuttujan `number` sisällöksi 8.

Tehdään vielä koodi, joka tutkii tarkemmin sitä, miten `int`-muuttujan sisältö on tallennettu muistiin. Koodi määrittelee `char`-osoittimen, johon se hakee muuttujan `number` osoitteen muistissa. Koodi olettaa, että `int`-muuttuja muodostuu neljästä tavusta ja tulostaa tavujen sisällön bittimuodossa.

```c
int number = 123456;
char *pointer = (char*)&number;

for (int pos = 0; pos < 4; pos++) {
    char byte = *(pointer + pos);
    printf("%d ", pos);
    for (int b = 7; b >= 0; b--) {
        if (byte & (1 << b)) printf("1");
        else printf("0");
    }
    printf("\n");
}
```

Koodin tulostus on seuraava:

```
0 01000000
1 11100010
2 00000001
3 00000000
```

Tässä tapauksessa luku 123456 on tallennettu muistiin neljänä tavuna little endian -muodossa, mikä tarkoittaa, että luvun bittiesitys saadaan lukemalla tavut lopusta alkuun: `00000000 00000001 11100010 01000000`.
