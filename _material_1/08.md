# 8. Käännösprosessi

## Esikäsittely

```console
$ gcc -E test.c -o test.i
```

## Käännös assemblyksi

```console
$ gcc -S test.c -o test.s
```

## Käännös binääriksi

```console
$ gcc -c test.c -o test.o
```

## Linkitys

```console
$ gcc test.o -o test
```
