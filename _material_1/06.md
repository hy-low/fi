# 6. Lisää C-kielestä

## Suoritusympäristö

Ohjelmalle voidaan antaa käynnistyksen yhteydessä parametreja, jotka voidaan käsitellä seuraavasti:

```c
int main(int argc, char **argv) {
    printf("%d\n", argc);
    for (int i = 0; i < argc; i++) {
        printf("%d: %s\n", i, argv[i]);
    }
}
```

Tässä on käytetty `main`-funktion pidempää muotoa, jossa `argc` kertoo parametrien määrän ja `argv` on merkkijonotaulukko, joka sisältää parametrit. Ensimmäinen parametri on ohjelman käynnistyskomento, ja seuraavat parametrit ovat mahdolliset sen jälkeen tulevat parametrit.

Ohjelman suoritus voi näyttää esimerkiksi seuraavalta:

```console
$ ./test apina banaani cembalo
4
0: ./test
1: apina
2: banaani
3: cembalo
```

Kun `main`-funktio palauttaa `int`-arvon, se voidaan tarkastaa ohjelman suorituksen jälkeen. Esimerkiksi seuraavan ohjelman paluuarvo on 123:

```c
int main(void) {
    return 123;
}
```

Linux-ympäristössä muuttuja `$?` sisältää ohjelman paluuarvon, joka voidaan tulostaa seuraavasti ohjelman suorituksen jälkeen:

```console
$ ./test
$ echo $?
123
```

Tavallinen tulkinta on, että arvo 0 tarkoittaa onnistunutta suoritusta ja muut arvot viittaavat virhetilanteisiin. Tätä voidaan hyödyntää esimerkiksi seuraavasti:

```console
$ ./test && echo "success"
```

Tässä `&&`-rakenne saa aikaan, että jos ohjelman paluuarvo on 0, suoritetaan myös seuraava komento `echo "success"`, ja muuten komentoa ei suoriteta.

<div class="note" markdown="1">
Jos `main`-funktiossa ei palauteta arvoa `return`-komennolla, C99-standardi määrittelee, että tällöin paluuarvo on automaattisesti 0. Alkuperäinen standardi ei määrittele, mitä funktio palauttaa tässä tapauksessa.
</div>

## Tiedostojen käsittely

Tiedoston sisältö muodostuu peräkkäisistä tavuista, joiden tulkinta riippuu tiedoston formaatista. Ohjelmoijan kannalta tiedostoa voi ajatella yleensä joko tekstitiedostona tai binääritiedostona:

- Tekstitiedosto on ihmisen luettavissa oleva tiedosto, joka muodostuu tekstiriveistä. Esimerkiksi C-ohjelman lähdekoodi on tekstitiedosto.

- Binääritiedosto muodostuu tavuista, jotka kuvaavat tiedoston sisällön tietyn formaatin mukaisesti. Esimerkiksi kuvat ja videot ovat binääritiedostoja.

Tarkastellaan esimerkkinä tiedostoa `aybabtu.txt`, jonka sisältönä on:

```
Operator: Main screen turn on.
Captain: It's you !!
CATS: How are you gentlemen !!
CATS: All your base are belong to us.
```

Voimme tutkia tiedoston sisältöä tavumuodossa esimerkiksi `xxd`-komennolla:

```console

```

Komento näyttää vierekkäin tiedoston sisällön tavuina ja merkkeinä. Jokainen tavu on esitetty heksalukuna. Tiedosto alkaa seuraavasti:

- Ensimmäinen tavu on heksalukuna `4f` ja vastaa merkkiä `O`.
- Toinen tavu on heksalukuna `70` ja vastaa merkkiä `p`.
- Kolmas tavu on heksalukuna `65` ja vastaa merkkiä `e`.

Tässä näkee myös, että jokainen rivinvaihto vastaa tavua `0a`.

### Tekstitiedoston käsittely

Seuraava koodi lukee tekstitiedoston sisällön rivi kerrallaan ja tulostaa luetut rivit:

```c
FILE *file = fopen("aybabtu.txt", "r");

char buffer[128];
int count = 0;

while (fgets(buffer, 128, file) != NULL) {
    count++;
    printf("%d: %s", count, buffer);
}

fclose(file);
```

Koodi tulostaa tiedoston sisällön näin:

```
1: Operator: Main screen turn on.
2: Captain: It's you !!
3: CATS: How are you gentlemen !!
4: CATS: All your base are belong to us.
```

Koodin toiminta on seuraava:

- Muuttuja `file` on tiedosto-osoitin, jonka kautta tiedostoa käsitellään.
- Funktio `fopen` avaa tiedoston käsittelyä varten. Parametri `"r"` tarkoittaa, että tiedosto avataan tekstitiedostona lukemista varten.
- Taulukko `buffer` varaa muistialueen, johon yksittäinen tiedoston rivi luetaan.
- Funktio `fgets` lukee rivin tiedostosta. Funktiolle annetaan osoitin taulukkoon, suurin sallittu luettava tavujen määrä (mukaan lukien nollatavu merkkijonon lopussa) sekä tiedosto-osoitin.
- Funktio `fgets` palauttaa osoittimen luetun rivin sisältävään muistialueeseen tai null-osoittimen, jos tiedosto päättyi tai tapahtui virhe.
- Koska luettu tiedoston rivi sisältää myös rivinvaihdon, funktiossa `printf` ei tulosteta erikseen rivinvaihtoa.
- Funktio `fclose` lopettaa avatun tiedoston käsittelyn.

Koodissa on oletuksena, että tiedoston jokainen rivi vie tilaa enintään 128 tavua. Jos rivi on pidempi, funktio `fgets` lukee rivin vain osittain ja jatkaa saman rivin lukemista seuraavalla kutsulla.

<div class="note" markdown="1">
Funktio `fgets` on kätevä funktio rivin lukemiseen, jonka käyttäminen on turvallista, kun funktiolle annettava muistialueen koko on sama kuin varattu taulukon koko. Tällöin ei ole puskuriylivuodon riskiä, koska tiedostossa oleva pitkä rivi ei voi mennä varatun muistialueen ulkopuolelle.

Funktiota voi käyttää myös rivin lukemiseen käyttäjältä seuraavasti:

```c
fgets(buffer, 128, stdin);
```

Tässä `stdin` on erityinen "tiedosto", joka viittaa standardisyötteeseen (standard input) eli oletuksena käyttäjältä tulevaan tietoon.
</div>

### Binääritiedoston käsittely

Seuraava koodi lukee binääritiedoston sisällön 16 tavun osissa ja tulostaa kunkin osan tavut heksamuodossa:

```c
FILE *file = fopen("aybabtu.txt", "rb");

char buffer[16];
int len;

while (len = fread(buffer, 1, 16, file)) {
    for (int i = 0; i < len; i++) {
        printf("%02x ", buffer[i]);
    }
    printf("\n");
}

fclose(file);
```

Koodi tulostaa tiedoston sisällön näin:

```
4f 70 65 72 61 74 6f 72 3a 20 4d 61 69 6e 20 73
63 72 65 65 6e 20 74 75 72 6e 20 6f 6e 2e 0a 43
61 70 74 61 69 6e 3a 20 49 74 27 73 20 79 6f 75
20 21 21 0a 43 41 54 53 3a 20 48 6f 77 20 61 72
65 20 79 6f 75 20 67 65 6e 74 6c 65 6d 65 6e 20
21 21 0a 43 41 54 53 3a 20 41 6c 6c 20 79 6f 75
72 20 62 61 73 65 20 61 72 65 20 62 65 6c 6f 6e
67 20 74 6f 20 75 73 2e 0a
```

Koodin toiminta on seuraava:

- Funktiolle `fopen` annetaan parametri `"rb"`, mikä tarkoittaa, että tiedosto avataan binäärimuodossa lukemista varten.
- Taulukko `buffer` sisältää tiedostosta kerrallaan luetut tavut.
- Funktio `fread` lukee tietoa tiedostosta. Funktion parametrit ovat osoitin taulukkoon, yhden tietoyksikön koko (tässä 1 eli yksi tavu), tietoyksiköiden määrä (tässä 16) ja tiedosto-osoitin.
- Funktion `fread` palautusarvo on luettujen tietoyksiköiden määrä. Kun määrä on 0, tiedosto päättyi tai tapahtui virhe.
- Tässä `while`-silmukka on rakennettu niin, että silmukka jatkuu niin kauan kuin tiedostosta saadaan luettua tietoa.
- Funktiossa `printf` merkintä `%02x` tarkoittaa, että tavun arvo tulostetaan heksamuodossa kahtena merkkinä.
