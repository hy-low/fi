# 1. Johdatus C-kieleen

## C-kielen historia

## Ensimmäinen ohjelma

Aloitetaan seuraavasta C-kielisestä ohjelmasta, joka tarkastaa, onko käyttäjän antama luku parillinen vai pariton:

```c
#include <stdio.h>

int main(void) {
    printf("Anna luku: ");
    int number;
    scanf("%d", &number);

    if (number % 2 == 0) {
        printf("Luku on parillinen\n");
    } else {
        printf("Luku on pariton\n");
    }

    return 0;
}
```

Ohjelman suoritus voi näyttää esimerkiksi seuraavalta:

```
Anna luku: 5
Luku on pariton
```

```
Anna luku: 42
Luku on parillinen
```

Tarkastellaan tarkemmin ohjelman rakennetta:

- Ohjelman alussa on rivi `#include <stdio.h>`, jotta ohjelmassa voidaan käyttää C-kielen standardikirjaston funktioita `printf` (tulostaminen) ja `scanf` (syötteen lukeminen).
- C-kielessä ohjelman suoritus alkaa pääfunktiosta, jonka nimi on `main`. Määrittely `int main(void)` tarkoittaa, että funktio palauttaa kokonaisluvun (`int`) ja sille ei anneta parametreja (`void`).
- Jokainen ohjelman komento on _lause_ (_statement_), jonka perässä on puolipiste (`;`).
- Ohjelma tulostaa tekstiä funktion `printf` avulla. Huomaa, että tulostetun tekstin loppuun ei tule automaattisesti rivinvaihtoa, vaan se tulee lisätä tarvittaessa itse (merkintä `\n`).
- Rivi `int number` määrittelee muuttujan, jonka nimi on `number` ja tyyppi on kokonaisluku (`int`). Tähän muuttujaan luetaan luku käyttäjältä.
- Ohjelma lukee käyttäjältä luvun funktion `scanf` avulla. Tässä `%d` ilmaisee, että funktion tulee lukea yksi kokonaisluku. Merkintä `&number` tarkoittaa, että funktiolle annetaan parametrina _osoitin_ muuttujaan `number` (myöhemmin selviää, miksi näin tehdään).
- Ohjelmassa on `if`-rakenne, joka selvittää luvun parillisuuden ja tulostaa rivin tekstiä.
- Rivi `return 0` palauttaa pääfunktiosta arvon 0, mikä tarkoittaa, että ohjelman suoritus päättyi onnistuneesti.

## Ehtolause

C-kielessä ehtolauseen voi muodostaa kahdella tavalla:

```c
if (ehto) lause
```

Tässä `lause` suoritetaan, jos `ehto` on tosi.

```c
if (ehto) lause1
else lause2
```

Tässä `lause1` suoritetaan, jos `ehto` on tosi, ja muuten `lause2` suoritetaan.

Esimerkiksi koodissa

```c
if (number % 2 == 0)
    printf("Luku on parillinen\n");
```

ehtona on `number % 2 == 0` eli muuttujan `number` arvon tulee olla parillinen. Jos tämä pätee, ohjelma tulostaa rivin tekstiä `printf`-funktiolla.

### Ehdon muodostaminen

Tavallisesti ehto muodostetaan vertailu- ja loogisten operaattoreiden avulla. Nämä toimivat samalla periaatteella kuin muissakin yleisissä ohjelmointikielissä.

- Vertailuoperaattorit: `==`, `!=`, `<`, `<=`, `>`, `>=`
- Loogiset operaattorit: `&&` (and), `||` (or), `!` (not)

Esimerkiksi ehto `(a >= 1 && a <= 5) || b != 1` on tosi, jos muuttujan `a` arvo on 1:n ja 5:n välillä tai jos muuttujan `b` arvo ei ole 1.

C-kielessä ei ole erillistä boolean-tyyppiä, vaan ehtona voi olla mikä tahansa lukuarvoinen _lauseke_ (_expression_). Tulkintana on, että ehto on tosi, jos lausekkeen arvo ei ole nolla, ja ehto on epätosi, jos lausekkeen arvo on nolla. Vertailu- ja loogiset operaattorit tuottavat lukuarvon 1 (tosi) tai 0 (epätosi).

<div class="note" markdown="1">
Klassinen bugi C-kielessä syntyy, kun koodissa on tarkoitus olla vertailuoperaattori `==` mutta sen sijasta onkin sijoitusoperaattori `=`. Esimerkiksi bugi voi esiintyä koodissa näin:

```c
if (number = 0)
    printf("Luku on nolla");
```

Koodissa on bugi, koska lauseke `number = 0` sijoittaa muuttujan `number` arvoksi 0:n. Tällaisen lausekkeen arvona on muuttujaan sijoitettu arvo eli tässä tapauksessa 0 eli epätosi. Niinpä muuttujan `number` sisällöstä riippumatta koodi nollaa muuttujan `number` eikä tulosta mitään.

Seuraava koodi toimii oikealla tavalla:

```c
if (number == 0)
    printf("Luku on nolla");
```

Nyt lauseke on `number == 0`, joka ilmaisee, onko muuttujan `number` arvona 0.
</div>

### Lohkot ehtolauseessa

Seuraavat koodit toimivat samalla tavalla:

```c
if (number % 2 == 0)
    printf("Luku on parillinen\n");
```

```c
if (number % 2 == 0) {
    printf("Luku on parillinen\n");
}
```

Jos ehdon toteutuessa suoritetaan yksittäinen komento, sen voi kirjoittaa sellaisenaan lauseena, jonka perässä on puolipiste. Kuitenkin tavallisempaa on, että ehdon toteutuessa suoritetaan aaltosulkeiden `{` ja `}` rajaama _lohko_ (_block_), joka sisältää yhden tai useamman lauseen. Lohko on itsessään lause ja siitä käytetään myös nimeä _koottu lause_ (_compound statement_).

Esimerkiksi seuraava koodi suorittaa kaksi `printf`-komentoa, jos käyttäjä on antanut oikean salasanan:

```c
if (password == 42) {
    printf("Tervetuloa!\n");
    printf("Annoit oikean salasanan\n");
}
```

<div class="note" markdown="1">
Vaikka ehdon toteutuessa suoritettaisiin vain yksittäinen komento, voi olla hyvä idea kirjoittaa se kuitenkin lohkon sisään. Tämä voi estää koodiin tulevan bugin siinä vaiheessa, kun koodia laajennetaan.

Esimerkiksi koodi

```c
if (password == 42)
    printf("Tervetuloa!\n");
```

toimii ilman lohkoa, mutta myöhemmin joku saattaa vahingossa laajentaa koodia seuraavasti:

```c
if (password == 42)
    printf("Tervetuloa!\n");
    printf("Annoit oikean salasanan\n");
```

Koska rakenteessa ei ole lohkoa, tulkintana on, että vain ensimmäinen `printf`-komento on rakenteen sisällä. Tämän takia koodi toimii samalla tavalla kuin seuraava koodi:

```c
if (password == 42) {
    printf("Tervetuloa!\n");
}
printf("Annoit oikean salasanan\n");
```

Tässä jälkimmäinen `printf`-komento suoritetaan ehdosta riippumatta, mikä ei ollut koodin tarkoitettu toimintatapa.
</div>

### Ehtojen ketjuttaminen

Tarkastellaan vielä tilannetta, jossa muuttujassa `suit` on kortin maa (1 = pata, 2 = ruutu, 3 = risti, 4 = hertta). Seuraava koodi tarkastaa, onko kortti pata:

```c
if (suit == 1) {
    printf("Kortti on pata");
} else {
    printf("Kortti ei ole pata");
}
```

C-kielessä ei ole `elseif`-tyyppistä avainsanaa, mutta ehtoja voi kuitenkin ketjuttaa seuraavasti tunnistamaan kaikki maat:

```cpp
if (suit == 1) {
    printf("Kortti on pata");
} else if (suit == 2) {
    printf("Kortti on ruutu");
} else if (suit == 3) {
    printf("Kortti on risti");
} else if (suit == 4) {
    printf("Kortti on hertta");
} else {
    printf("???");
}
```

Tämä toimii, koska `else`-haarassa oleva lause voi olla myös `if`-lause. Yllä oleva koodi toimii siis samalla tavalla kuin seuraava koodi:

```c
if (suit == 1) {
    printf("Kortti on pata");
} else {
    if (suit == 2) {
        printf("Kortti on ruutu");
    } else {
        if (suit == 3) {
            printf("Kortti on risti");
        } else {
            if (suit == 4) {
                printf("Kortti on hertta");
            } else {
                printf("???");
            }
        }
    }
}
```
