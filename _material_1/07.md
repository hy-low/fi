# 7. Ohjelmistokehitys

## Suoritusympäristö

Ohjelmalle voidaan antaa käynnistyksen yhteydessä parametreja, jotka voidaan käsitellä seuraavasti:

```c
int main(int argc, char **argv) {
    printf("%d\n", argc);
    for (int i = 0; i < argc; i++) {
        printf("%d: %s\n", i, argv[i]);
    }
}
```

Tässä on käytetty `main`-funktion pidempää muotoa, jossa `argc` kertoo parametrien määrän ja `argv` on merkkijonotaulukko, joka sisältää parametrit. Ensimmäinen parametri on ohjelman käynnistyskomento, ja seuraavat parametrit ovat mahdolliset sen jälkeen tulevat parametrit.

Ohjelman suoritus voi näyttää esimerkiksi seuraavalta:

```console
$ ./test apina banaani cembalo
4
0: ./test
1: apina
2: banaani
3: cembalo
```

Kun `main`-funktio palauttaa `int`-arvon, se voidaan tarkastaa ohjelman suorituksen jälkeen. Esimerkiksi seuraavan ohjelman paluuarvo on 123:

```c
int main(void) {
    return 123;
}
```

Linux-ympäristössä muuttuja `$?` sisältää ohjelman paluuarvon, joka voidaan tulostaa seuraavasti ohjelman suorituksen jälkeen:

```console
$ ./test
$ echo $?
123
```

Tavallinen tulkinta on, että arvo 0 tarkoittaa onnistunutta suoritusta ja muut arvot viittaavat virhetilanteisiin. Tätä voidaan hyödyntää esimerkiksi seuraavasti:

```console
$ ./test && echo "success"
```

Tässä `&&`-rakenne saa aikaan, että jos ohjelman paluuarvo on 0, suoritetaan myös seuraava komento `echo "success"`, ja muuten komentoa ei suoriteta.

<div class="note" markdown="1">
Jos `main`-funktiossa ei palauteta arvoa `return`-komennolla, C99-standardi määrittelee, että tällöin paluuarvo on automaattisesti 0. Alkuperäinen standardi ei määrittele, mitä funktio palauttaa tässä tapauksessa.
</div>

## Koodi tiedostoissa

C-ohjelman koodi voi muodostua useasta tiedostosta, joissa on viittauksia toisiinsa. Esimerkiksi seuraava ohjelma muodostuu kahdesta tiedostosta:

{: .code-title }
main.c
```c
extern void print_message(char*);

int main(void) {
    print_message("We get signal.");
    print_message("Main screen turn on.");
}
```

{: .code-title }
message.c
```c
#include <stdio.h>
#include <string.h>

void print_stars(int n) {
    for (int i = 0; i < n; i++) {
        printf("*");
    }
    printf("\n");
}

void print_message(char *message) {
    int n = strlen(message);
    print_stars(n + 4);
    printf("* %s *\n", message);
    print_stars(n + 4);
}
```

Tässä ohjelmassa pääfunktio `main` on määritelty tiedostossa `main.c`. Pääfunktio kutsuu funktiota `print_message`, joka on määritelty tiedostossa `message.c`. Ohjelman voi kääntää seuraavalla komennolla:

```console
$ gcc main.c message.c -o main
```

Tämän jälkeen ohjelman voi suorittaa seuraavasti:

```console
$ ./main
******************
* We get signal. *
******************
************************
* Main screen turn on. *
************************
```

Tiedoston `main.c` alussa on funktion `print_message` esittely, joka antaa tiedon siitä, että kyseinen funktio on olemassa ja se määritellään jossain muualla.

<div class="note" markdown="1">
C-kielessä jokainen kooditiedosto (`.c`) on erillinen _käännösyksikkö_ (_translation unit_), joka käännetään ensin objektitiedostoksi. Tämän jälkeen objektitiedostot linkitetään lopulliseksi suoritettavaksi ohjelmaksi.

Teimme äsken kaikki nämä vaiheet samalla komennolla, mutta vaiheet on mahdollista tehdä myös erikseen. Seuraavat komennot kääntävät tiedostot `main.c` ja `message.c` objektitiedostoiksi `main.o` ja `message.o`:

```console
$ gcc -c main.c -o main.o
$ gcc -c message.c -o message.o
```

Tämän jälkeen seuraava komento linkittää objektitiedostot suoritettavaksi ohjelmaksi:

```console
$ gcc main.o message.o -o main
```

Tutustumme tarkemmin C-ohjelman käännösprosessiin materiaalin seuraavassa luvussa.
</div>

### Näkyvyys ja esittely

C-kielessä tiedostossa määritellyt funktiot ja muuttujat ovat oletuksena näkyvissä koko ohjelman laajuisesti. Toisessa tiedostossa määriteltyä funktiota tai muuttujaa voi käyttää, kunhan se esitellään ennen käyttämistä.

Esimerkiksi seuraavassa tiedostossa `main.c` käytetään funktiota `secret_message` ja muuttujaa `secret_value`, jotka on määritelty tiedostossa `secret.c`.

{: .code-title }
main.c
```c
extern void secret_message(void);
extern int secret_value;

int main(void) {
    secret_message();
    printf("%d\n", secret_value);
}
```

{: .code-title }
secret.c
```c
#include <stdio.h>

int secret_value = 1337;

void secret_message(void) {
    printf("Main screen turn on.\n")
}
```

Erona toisessa tiedostossa määritellyn funktion ja muuttujan esittelyssä on, että funktion esittelyssä avainsana `extern` ei ole pakollinen mutta muuttujan esittelyssä se on pakollinen. Yllä olevassa tiedostossa `main.c` funktion `secret_message` voisi siis esitellä myös lyhemmin seuraavasti:

```c
void secret_message(void);
```

Kuitenkin avainsana `extern` selventää myös funktion tapauksessa, että kyseessä on jossain muualla määritelty funktio.

Koska funktio ja muuttuja näkyy oletuksena kaikkialla, kahdessa tiedostossa ei voi olla samannimisen funktion tai muuttujan määrittelyä. Tässä tulisi ongelmaksi, ettei olisi selvää, kumpaa funktiota tai muuttujaa tulisi käyttää.

### Paikallinen näkyvyys

Avainsana `static` määrittelee, että funktion tai muuttujan näkyvyys on paikallinen eli sitä voi käyttää vain tiedostossa, jossa se on määritelty.

Seuraavassa esimerkissä funktio `print_stars` on määritelty paikalliseksi, mikä on perusteltua, koska kyseessä on funktion `print_message` apufunktio, jota ei ole tarkoitus kutsua muualta.

```c
static void print_stars(int n) {
    for (int i = 0; i < n; i++) {
        printf("*");
    }
    printf("\n");
}

void print_message(char *message) {
    int n = strlen(message);
    print_stars(n + 4);
    printf("* %s *\n", message);
    print_stars(n + 4);
}
```

Kun funktion tai muuttujan määrittelyssä on avainsana `static`, kahdessa tiedostossa voi olla samanniminen funktio tai muuttuja, koska määrittely on paikallinen eikä näy muihin tiedostoihin.

## Projektin rakenne

Tavallinen tapa toteuttaa C-kielisen projektin rakenne on lisätä kullekin kooditiedostolle (`.c`) otsikkotiedosto (`.h`), joka esimerkiksi esittelee tiedostossa määritellyt funktiot. Tämän jälkeen halutun otsikkotiedoston sisältö saadaan mukaan `#include`-komennon avulla.

Olemme käyttäneet `#include`-komentoa aiemmin standardikirjaston tapauksessa, jolloin otsikkotiedoston nimi annetaan kulmasulkujen `<` ja `>` sisällä. Esimerkiksi

```c
#include <stdio.h>
```

ottaa mukaan standardikirjaston otsikkotiedoston `stdio.h` sisällön. Muiden otsikkotiedostojen tapauksessa otsikkotiedoston nimi kirjoitetaan kuitenkin lainausmerkkien sisään. Esimerkiksi

```c
#include "message.h"
```

ottaa mukaan otsikkotiedoston `message.h` sisällön.

### Esimerkki

Seuraavassa esimerkissä otsikkotiedosto `message.h` sisältää funktion `print_message` määrittelyn ja kooditiedosto `message.c` sisältää funktion toteutuksen. Otsikkotiedosto liitetään mukaan tiedostossa `main.c`.

{: .code-title }
main.c
```c
#include "message.h"

int main(void) {
    print_message("We get signal.");
    print_message("Main screen turn on.");
}
```

{: .code-title }
message.h
```c
extern void print_message(char*);
```

{: .code-title }
message.c
```c
#include <stdio.h>
#include <string.h>

static void print_stars(int n) {
    for (int i = 0; i < n; i++) {
        printf("*");
    }
    printf("\n");
}

void print_message(char *message) {
    int n = strlen(message);
    print_stars(n + 4);
    printf("* %s *\n", message);
    print_stars(n + 4);
}
```

Ohjelman voi kääntää komennolla

```console
$ gcc main.c message.c -o main
```

ja ohjelman voi sitten suorittaa seuraavasti:

```console
$ ./main
******************
* We get signal. *
******************
************************
* Main screen turn on. *
************************
```

Tässä otsikkotiedoston `message.h` hyötynä on, että kun halutaan käyttää tiedoston `message.c` sisältöä, riittää laittaa koodin alkuun `#include`-komento, joka ottaa mukaan otsikkotiedoston `message.h`.

## Ulkoiset kirjastot

Luvussa 1 tarkastelimme seuraavaa esimerkkiohjelmaa, joka laskee käyttäjän antaman luvun kertoman:

```c
#include <stdio.h>

int main(void) {
    printf("Anna luku: ");
    int number;
    scanf("%d", &number);

    long factorial = 1;
    for (int x = 1; x <= number; x++) {
        factorial *= x;
    }

    printf("Luvun %d kertoma on %ld\n", number, factorial);
}
```

Tämän ohjelman rajoituksena on, että emme voi laskea kovin suurta kertomaa, koska C:n lukutyypit ovat rajoitetun kokoisia. Esimerkiksi tyyppi `long` on tavallisesti 64-bittinen, minkä takia siihen mahtuu enintään luvun 20 kertoma:

```console
Anna luku: 20
Luvun 20 kertoma on 2432902008176640000
```

```console
Anna luku: 21
Luvun 21 kertoma on -4249290049419214848
```

Tässä luvun 21 kertomaksi tulee negatiivinen tulos merkkinä siitä, että luku on pyörähtänyt ympäri ylivuodon seurauksena.

C-kielen standardikirjastossa ei ole tapaa käsitellä suuria kokonaislukuja, mutta voimme käyttää tähän ulkoista GMP-kirjastoa, jolla pystyy käsittelemään mielivaltaisen suuria kokonaislukuja.

Ensimmäinen vaihe ulkoisen kirjaston käyttämisessä on asentaa kirjasto kehitysympäristöön. Esimerkiksi Ubuntu Linuxissa voidaan asentaa paketti `libgmp-dev` seuraavasti:

```console
$ sudo apt install libgmp-dev
```

Tämän jälkeen koodissa voidaan käyttää otsikkotiedostoa `gmp.h`, joka ottaa mukaan GMP-kirjaston sisällön.

Seuraavassa on uusi toteutus kertoman laskevasta ohjelmasta käyttäen GMP-kirjastoa. Tässä toteutuksessa tuloksen suuruutta ei ole rajoitettu, vaan ohjelmalla voi laskea hyvin suurenkin kertoman.

```c
#include <stdio.h>
#include <gmp.h>

int main(void) {
    printf("Anna luku: ");
    int number;
    scanf("%d", &number);

    mpz_t factorial;
    mpz_init(factorial);
    mpz_set_ui(factorial, 1);

    for (int x = 1; x <= number; x++) {
        mpz_mul_ui(factorial, factorial, x);
    }

    gmp_printf("Luvun %d kertoma on %Zd\n", number, factorial);
}
```

Seuraava komento kääntää ohjelman:

```console
$ gcc factorial.c -o factorial -lgmp
```

Tässä komennossa on mukana lippu `-lgmp`, jonka ansiosta GMP-kirjasto linkitetään mukaan käännöksessä.

Tämän jälkeen ohjelman voi suorittaa seuraavasti:

```console
Anna luku: 100
Luvun 100 kertoma on 93326215443944152681699238856266700490715968264381621468592963895217599993229915608941463976156518286253697920827223758251185210916864000000000000000000000000
```

GMP-kirjastoa käytetään koodissa seuraavasti:

- Koodin alussa on komento `#include <gmp.h>`, joka tuo mukaan GMP-kirjastoon liittyvät määrittelyt ja funktiot.
- Tyyppi `mpz_t` tarkoittaa mielivaltaisen suurta kokonaislukua.
- Funktio `mpz_init` alustaa muistialueen, johon tallennetaan suuri kokonaisluku.
- Funktio `mpz_set_ui` asettaa suurelle kokonaisluvulle arvon. Merkintä `ui` tarkoittaa, että parametrina on etumerkitön kokonaisluku.
- Funktio `mpz_mul_ui` kertoo suuren kokonaisluvun annetulla luvulla, joka on jälleen etumerkitön kokonaisluku.
- Funktio `gmp_printf` on muunnelma `printf`-funktiosta, jonka avulla pystyy tulostamaan myös GMP-kirjaston lukuja.

Itse asiassa GMP-kirjastossa on myös suorempi tapa laskea luvun kertoma käyttäen valmista funktiota `mpz_fac_ui` seuraavasti:

```c
#include <stdio.h>
#include <gmp.h>

int main(void) {
    printf("Anna luku: ");
    int number;
    scanf("%d", &number);

    mpz_t factorial;
    mpz_init(factorial);
    mpz_fac_ui(factorial, number);

    gmp_printf("Luvun %d kertoma on %Zd\n", number, factorial);
}
```
