# 7. Ohjelmistokehitys

## Koodi tiedostoissa

C-ohjelman koodi voi muodostua useasta tiedostosta, joissa on viittauksia toisiinsa. Esimerkiksi seuraava ohjelma muodostuu kahdesta tiedostosta:

{: .code-title }
main.c
```c
extern void print_message(char*);

int main(void) {
    print_message("We get signal.");
    print_message("Main screen turn on.");
}
```

{: .code-title }
message.c
```c
#include <stdio.h>
#include <string.h>

void print_stars(int n) {
    for (int i = 0; i < n; i++) {
        printf("*");
    }
    printf("\n");
}

void print_message(char *message) {
    int n = strlen(message);
    print_stars(n + 4);
    printf("* %s *\n", message);
    print_stars(n + 4);
}
```

Tässä ohjelmassa pääfunktio `main` on määritelty tiedostossa `main.c`. Pääfunktio kutsuu funktiota `print_message`, joka on määritelty tiedostossa `message.c`. Ohjelman voi kääntää seuraavalla komennolla:

```console
$ gcc main.c message.c -o main
```

Tämän jälkeen ohjelman voi suorittaa seuraavasti:

```console
$ ./main
******************
* We get signal. *
******************
************************
* Main screen turn on. *
************************
```

Tiedoston `main.c` alussa on funktion `print_message` esittely, joka antaa tiedon siitä, että kyseinen funktio on olemassa ja se määritellään jossain muualla.

### Näkyvyys ja esittely

C-kielessä tiedostossa määritellyt funktiot ja muuttujat ovat oletuksena näkyvissä koko ohjelman laajuisesti. Toisessa tiedostossa määriteltyä funktiota tai muuttujaa voi käyttää, kunhan se esitellään ennen käyttämistä.

Esimerkiksi seuraavassa tiedostossa `main.c` käytetään funktiota `secret_message` ja muuttujaa `secret_value`, jotka on määritelty tiedostossa `secret.c`.

{: .code-title }
main.c
```c
extern void secret_message(void);
extern int secret_value;

int main(void) {
    secret_message();
    printf("%d\n", secret_value);
}
```

{: .code-title }
secret.c
```c
#include <stdio.h>

int secret_value = 1337;

void secret_message(void) {
    printf("Main screen turn on.\n")
}
```

Erona toisessa tiedostossa määritellyn funktion ja muuttujan esittelyssä on, että funktion esittelyssä avainsana `extern` ei ole pakollinen mutta muuttujan esittelyssä se on pakollinen. Yllä olevassa tiedostossa `main.c` funktion `secret_message` voisi siis esitellä myös lyhemmin seuraavasti:

```c
void secret_message(void);
```

Kuitenkin avainsana `extern` selventää myös funktion tapauksessa, että kyseessä on jossain muualla määritelty funktio.

Koska funktio ja muuttuja näkyy oletuksena kaikkialla, kahdessa tiedostossa ei voi olla samannimisen funktion tai muuttujan määrittelyä. Tässä tulisi ongelmaksi, ettei olisi selvää, kumpaa funktiota tai muuttujaa tulisi käyttää.

### Paikallinen näkyvyys

Avainsana `static` määrittelee, että funktion tai muuttujan näkyvyys on paikallinen eli sitä voi käyttää vain tiedostossa, jossa se on määritelty.

Seuraavassa esimerkissä funktio `print_stars` on määritelty paikalliseksi, mikä on perusteltua, koska kyseessä on funktion `print_message` apufunktio, jota ei ole tarkoitus kutsua muualta.

```c
static void print_stars(int n) {
    for (int i = 0; i < n; i++) {
        printf("*");
    }
    printf("\n");
}

void print_message(char *message) {
    int n = strlen(message);
    print_stars(n + 4);
    printf("* %s *\n", message);
    print_stars(n + 4);
}
```

Kun funktion tai muuttujan määrittelyssä on avainsana `static`, kahdessa tiedostossa voi olla samanniminen funktio tai muuttuja, koska määrittely on paikallinen eikä näy muihin tiedostoihin.
