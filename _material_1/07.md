# 7. Ohjelmistokehitys

## Koodi tiedostoissa

C-ohjelman koodi muodostuu yleensä useasta tiedostosta, joissa on viittauksia toisiinsa. Esimerkiksi seuraava ohjelma muodostuu kahdesta tiedostosta:

{: .code-title }
main.c
```c
extern void print_message(char*);

int main(void) {
    print_message("We get signal.");
    print_message("Main screen turn on.");
}
```

Tiedostossa `main.c` on ohjelman pääfunktio `main`, joka kutsuu muualla määriteltyä funktiota `print_message`. Tiedoston alussa on funktion `print_message` esittely, joka näyttää, miten muualla määriteltyä funktiota voidaan kutsua.

{: .code-title }
message.c
```c
#include <stdio.h>
#include <string.h>

void print_stars(int n) {
    for (int i = 0; i < n; i++) {
        printf("*");
    }
    printf("\n");
}

void print_message(char *message) {
    int n = strlen(message);
    print_stars(n + 4);
    printf("* %s *\n", message);
    print_stars(n + 4);
}
```

Tiedostossa `message.c` on funktion `print_message` määrittely. Funktio kutsuu funktiota `print_stars`, joka on myös määritelty samassa tiedostossa.

Ohjelman voi kääntää seuraavalla komennolla:

```console
$ gcc main.c message.c -o main
```

Tässä komennossa annetaan kaksi kooditiedostoa (`main.c` ja `message.c`), jotka käännetään binääritiedostoksi `main`.

Käännöksen jälkeen ohjelman voi suorittaa seuraavasti:

```console
$ ./main
******************
* We get signal. *
******************
************************
* Main screen turn on. *
************************
```

<div class="note" markdown="1">
C-kielessä jokainen kooditiedosto (`.c`) on erillinen _käännösyksikkö_ (_translation unit_), joka käännetään objektitiedostoksi.

Ohjelman käännöksessä kaikki kooditiedostot käännetään ensin objektitiedostoiksi. Tämän jälkeen objektitiedostot linkitetään lopulliseksi suoritettavaksi binääritiedostoksi.

Teimme äsken koko käännöksen samalla komennolla, mutta käännöksen vaiheet on mahdollista tehdä myös erikseen. Seuraavat komennot kääntävät tiedostot `main.c` ja `message.c` objektitiedostoiksi `main.o` ja `message.o`:

```console
$ gcc -c main.c -o main.o
$ gcc -c message.c -o message.o
```

Tämän jälkeen objektitiedostot voidaan linkittää suoritettavaksi ohjelmaksi:

```console
$ gcc main.o message.o -o main
```
</div>

### Näkyvyys ja esittely

C-kielessä tiedostossa määritellyt funktiot ja muuttujat ovat oletuksena näkyvissä koko ohjelman laajuisesti. Toisessa tiedostossa määriteltyä funktiota tai muuttujaa voi käyttää, kunhan se esitellään ennen käyttämistä.

Esimerkiksi seuraavassa tiedostossa `main.c` käytetään funktiota `secret_message` ja muuttujaa `secret_value`, jotka on määritelty tiedostossa `secret.c`.

{: .code-title }
main.c
```c
extern void secret_message(void);
extern int secret_value;

int main(void) {
    secret_message();
    printf("%d\n", secret_value);
}
```

{: .code-title }
secret.c
```c
#include <stdio.h>

int secret_value = 1337;

void secret_message(void) {
    printf("Main screen turn on.\n")
}
```

Toisessa tiedostossa määritellyn funktion esittelyssä avainsana `extern` ei ole pakollinen, mutta toisessa tiedostossa määritellyn muuttujan esittelyssä se on pakollinen. Funktion `secret_message` voi siis esitellä tiedostossa `main.c` myös lyhyemmin seuraavasti:

```c
void secret_message(void);
```

Kuitenkin avainsana `extern` selventää myös funktion tapauksessa, että kyseessä on jossain muualla määritelty funktio.

<div class="note" markdown="1">
Muuttujan tapauksessa avainsana `extern` oikeastaan tuo esille, että kyseessä on muuttujan esittely eikä määrittely. Koodi

```c
int secret_value;
```

ei voi olla muuttujan esittely, koska tämä koodi määrittelee muuttujan, jonka alkuarvoksi tulee 0.
</div>

Koska funktiot ja muuttujat näkyvät oletuksena kaikkialla, kahdessa tiedostossa ei voi olla samannimisen funktion tai muuttujan määrittelyä. Tässä tulisi ongelmaksi, ettei olisi selvää, kumpaa funktiota tai muuttujaa tulisi käyttää.

### Paikallinen näkyvyys

Avainsana `static` ilmaisee, että funktion tai muuttujan näkyvyys on paikallinen eli sitä voi käyttää vain tiedostossa, jossa se on määritelty.

Esimerkiksi seuraavassa koodissa funktio `print_stars` on määritelty paikalliseksi, mikä on perusteltua, koska kyseessä on funktion `print_message` apufunktio, jota ei ole tarkoitus kutsua muualta.

```c
static void print_stars(int n) {
    for (int i = 0; i < n; i++) {
        printf("*");
    }
    printf("\n");
}

void print_message(char *message) {
    int n = strlen(message);
    print_stars(n + 4);
    printf("* %s *\n", message);
    print_stars(n + 4);
}
```

Kun funktion tai muuttujan määrittelyssä on avainsana `static`, kahdessa tiedostossa voi olla samanniminen funktio tai muuttuja, koska määrittely on paikallinen eikä näy muihin tiedostoihin.

## Projektin rakenne

Tavallinen tapa rakentaa C-kielinen projekti on lisätä kullekin kooditiedostolle (`.c`) otsikkotiedosto (`.h`), joka esimerkiksi esittelee kooditiedoston funktiot, joita voidaan kutsua muista kooditiedostoista. Tämän jälkeen otsikkotiedosto voidaan ottaa mukaan kooditiedostoissa `#include`-komennon avulla.

Olemme käyttäneet `#include`-komentoa aiemmin standardikirjaston yhteydessä, jolloin otsikkotiedoston nimi annetaan kulmasulkujen `<` ja `>` sisällä. Esimerkiksi seuraava komento ottaa mukaan tiedoston `stdio.h` sisällön:

```c
#include <stdio.h>
```

ottaa mukaan standardikirjaston otsikkotiedoston `stdio.h` sisällön. Standardikirjaston ulkopuolisten otsikkotiedostojen nimet kirjoitetaan lainausmerkkien sisään. Esimerkiksi seuraava komento ottaa mukaan tiedoston `message.h` sisällön:

```c
#include "message.h"
```

### Otsikkotiedoston käyttäminen

Seuraavassa esimerkissä tiedostossa `main.c` määritelty pääfunktio `main` kutsuu funktiota `print_message`. Tiedosto `message.h` sisältää funktion `print_message` esittelyn, jonka perusteella funktiota voidaan kutsua. Tiedosto `message.c` puolestaan sisältää funktion määrittelyn.

{: .code-title }
main.c
```c
#include "message.h"

int main(void) {
    print_message("We get signal.");
    print_message("Main screen turn on.");
}
```

{: .code-title }
message.h
```c
void print_message(char*);
```

{: .code-title }
message.c
```c
#include "message.h"
#include <stdio.h>
#include <string.h>

static void print_stars(int n) {
    for (int i = 0; i < n; i++) {
        printf("*");
    }
    printf("\n");
}

void print_message(char *message) {
    int n = strlen(message);
    print_stars(n + 4);
    printf("* %s *\n", message);
    print_stars(n + 4);
}
```

Ohjelman voi kääntää ja suorittaa seuraavasti:

```console
$ gcc main.c message.c -o main
$ ./main
******************
* We get signal. *
******************
************************
* Main screen turn on. *
************************
```

Tässä otsikkotiedoston `message.h` hyötynä on, että kun halutaan käyttää tiedoston `message.c` sisältöä, riittää laittaa koodin alkuun `#include`-komento, joka ottaa mukaan otsikkotiedoston `message.h`.

<div class="note" markdown="1">
Itse asiassa tiedostossa `message.c` ei olisi pakko olla riviä

```c
#include "message.h"
```

koska tiedostossa on varsinainen funktion `print_message` määrittely. Kuitenkin on hyvä käytäntö lisätä tämä rivi esimerkiksi sen takia, että kääntäjä varmistaa funktion esittelyn ja määrittelyn yhteensopivuuden.
</div>

## Ulkoiset kirjastot

Luvussa 1 tarkastelimme seuraavaa esimerkkiohjelmaa, joka laskee käyttäjän antaman luvun kertoman:

```c
#include <stdio.h>

int main(void) {
    printf("Anna luku: ");
    int number;
    scanf("%d", &number);

    long factorial = 1;
    for (int x = 1; x <= number; x++) {
        factorial *= x;
    }

    printf("Luvun %d kertoma on %ld\n", number, factorial);
}
```

Tämän ohjelman rajoituksena on, että emme voi laskea kovin suurta kertomaa, koska C:n lukutyypit ovat rajoitetun kokoisia. Esimerkiksi tyyppi `long` on tavallisesti 64-bittinen, minkä takia siihen mahtuu enintään luvun 20 kertoma:

```console
Anna luku: 20
Luvun 20 kertoma on 2432902008176640000
```

```console
Anna luku: 21
Luvun 21 kertoma on -4249290049419214848
```

Tässä luvun 21 kertomaksi tulee negatiivinen tulos merkkinä siitä, että luku on pyörähtänyt ympäri ylivuodon seurauksena.

C-kielen standardikirjastossa ei ole tapaa käsitellä suuria kokonaislukuja, mutta voimme käyttää tähän ulkoista GMP-kirjastoa, jolla pystyy käsittelemään mielivaltaisen suuria kokonaislukuja.

Ensimmäinen vaihe ulkoisen kirjaston käyttämisessä on asentaa kirjasto kehitysympäristöön. Esimerkiksi Ubuntu Linuxissa voidaan asentaa paketti `libgmp-dev` seuraavasti:

```console
$ sudo apt install libgmp-dev
```

Tämän jälkeen koodissa voidaan käyttää otsikkotiedostoa `gmp.h`, joka ottaa mukaan GMP-kirjaston sisällön.

Seuraavassa on uusi toteutus kertoman laskevasta ohjelmasta käyttäen GMP-kirjastoa. Tässä toteutuksessa tuloksen suuruutta ei ole rajoitettu, vaan ohjelmalla voi laskea hyvin suurenkin kertoman.

```c
#include <stdio.h>
#include <gmp.h>

int main(void) {
    printf("Anna luku: ");
    int number;
    scanf("%d", &number);

    mpz_t factorial;
    mpz_init(factorial);
    mpz_set_ui(factorial, 1);

    for (int x = 1; x <= number; x++) {
        mpz_mul_ui(factorial, factorial, x);
    }

    gmp_printf("Luvun %d kertoma on %Zd\n", number, factorial);
}
```

Seuraava komento kääntää ohjelman:

```console
$ gcc factorial.c -o factorial -lgmp
```

Tässä komennossa on mukana lippu `-lgmp`, jonka ansiosta GMP-kirjasto linkitetään mukaan käännöksessä.

Tämän jälkeen ohjelman voi suorittaa seuraavasti:

```console
Anna luku: 100
Luvun 100 kertoma on 93326215443944152681699238856266700490715968264381621468592963895217599993229915608941463976156518286253697920827223758251185210916864000000000000000000000000
```

GMP-kirjastoa käytetään koodissa seuraavasti:

- Koodin alussa on komento `#include <gmp.h>`, joka tuo mukaan GMP-kirjastoon liittyvät määrittelyt ja funktiot.
- Tyyppi `mpz_t` tarkoittaa mielivaltaisen suurta kokonaislukua.
- Funktio `mpz_init` alustaa muistialueen, johon tallennetaan suuri kokonaisluku.
- Funktio `mpz_set_ui` asettaa suurelle kokonaisluvulle arvon. Merkintä `ui` tarkoittaa, että parametrina on etumerkitön kokonaisluku.
- Funktio `mpz_mul_ui` kertoo suuren kokonaisluvun annetulla luvulla, joka on jälleen etumerkitön kokonaisluku.
- Funktio `gmp_printf` on muunnelma `printf`-funktiosta, jonka avulla pystyy tulostamaan myös GMP-kirjaston lukuja.

Itse asiassa GMP-kirjastossa on myös suorempi tapa laskea luvun kertoma käyttäen valmista funktiota `mpz_fac_ui` seuraavasti:

```c
#include <stdio.h>
#include <gmp.h>

int main(void) {
    printf("Anna luku: ");
    int number;
    scanf("%d", &number);

    mpz_t factorial;
    mpz_init(factorial);
    mpz_fac_ui(factorial, number);

    gmp_printf("Luvun %d kertoma on %Zd\n", number, factorial);
}
```
