# 3. Tietorakenteet

## Taulukko

Matalan tason ohjelmoinnin perustietorakenne on _taulukko_ (_array_), joka muodostuu peräkkäisistä muistissa olevista alkioista.

Tavallinen tapa määritellä taulukko C-kielessä on seuraava:

```c
int array[8];
```

Tässä `array` on taulukko, jonka koko on 8 alkiota. Jokainen taulukon alkio on `int`-tyyppinen kokonaisluku. Taulukkoa indeksoidaan kokonaisluvuilla nollasta alkaen samaan tapaan kuin muissakin ohjelmointikielissä. Esimerkiksi `array[2]` viittaa taulukon alkioon, joka on indeksissä 2.

<div class="note" markdown="1">
Kun C-kieli kehitettiin 1970-luvulla, nollaindeksointi oli itse asiassa uutta ajattelua. Monessa vanhan ajan ohjelmointikielessä indeksointi alkoi ykkösestä tai alkukohdan sai valita itse. C:n suosiolla on saattanut olla suuri vaikutus siihen, että nollaindeksointi on nykyään vakiintunut tapa ohjelmoinnissa.
</div>

Tässä on vielä toinen tapa määritellä taulukko, jossa määrittelyn yhteydessä annetaan taulukon alkusisältö:

```c
int array[] = {3, 1, 4, 1, 5, 9, 2, 6};
```

Koska taulukon alkiot on annettu listana taulukon määrittelyssä, taulukon kooksi tulee tässä tapauksessa automaattisesti 8 alkiota.

Taulukon voi myös määritellä antamalla _osan_ taulukon sisällöstä:

```c
int array[8] = {1, 2, 3};
```

Tässä annetut alkiot sijoitetaan taulukon alkuun ja kaikki muut alkiot saavat alkuarvon 0. Yllä oleva määrittely tarkoittaa siis samaa kuin:

```c
int array[8] = {1, 2, 3, 0, 0, 0, 0, 0};
```

<div class="note" markdown="1">
Tähän syntaksiin liittyy yksi C-kielen sudenkuopista. Kun tarkoituksena on alustaa koko taulukko luvulla 0, seuraava syntaksi toimii:

```c
int array[8] = {0};
```

Kuitenkin seuraava syntaksi _ei_ alusta koko taulukkoa luvulla 1:

```c
int array[8] = {1};
```

Tässä vain taulukon ensimmäinen alkio saa arvon 1 ja kaikki muut alkiot saavat arvon 0 eli taulukko onkin alustettu näin:

```c
int array[8] = {1, 0, 0, 0, 0, 0, 0, 0};
```
</div>

### Taulukon käsittely

Seuraava koodi tulostaa taulukon alkiot `for`-silmukan avulla:

```c
int array[] = {3, 1, 4, 1, 5, 9, 2, 6};
int size = 8;

for (int i = 0; i < size; i++) {
    printf("%d ", array[i]);
}
printf("\n");
```

Koodin tuloksena on:

```
3 1 4 1 5 9 2 6
```

Tässä muuttujassa `size` on muistissa taulukon koko, jota sitten käytetään silmukassa. C-ohjelmoinnissa on usein kätevää säilyttää muuttujassa tällaista tietoa, koska taulukon koon selvittäminen tyhjästä olisi tilanteesta riippuen hankalaa tai mahdotonta.

Yllä olevassa koodissa voisi käyttää syntaksia `sizeof(array)`, joka antaa taulukon koon tavuina eli tässä tapauksessa tuloksen 32 (8 alkiota, kunkin alkion koko 4 tavua). Taulukon alkioiden määrän voisi siis laskea kaavalla `sizeof(array) / sizeof(int)`, mutta tämä on melko monimutkainen kaava.

C-kielisen ohjelman suorituksen aikana ei valvota, onko taulukon käsittelyssä käytetty indeksi todella taulukon sisällä. Jos indeksi on taulukon ulkopuolella, ohjelma saattaa käsitellä muistia väärästä kohdasta ja toimia oudolla tavalla. Seuraava koodi havainnollistaa asiaa:

```c
int a[4] = {0};
int b[4] = {0};
a[4] = 123;
printf("%d\n", b[0]);
```

Tämän koodin suorittaminen antoi yllättävän tuloksen:

```
123
```

Taulukkoon `a` sijoitettu luku 123 menikin taulukkoon `b`? Tässä koodissa on bugina, että luku sijoitetaan taulukon `a` indeksiin 4, joka on taulukon ulkopuolella. Koodin voi kuitenkin suorittaa ja tässä tapauksessa taulukot `a` ja `b` olivat peräkkäin muistissa, minkä takia luku 123 menikin taulukon `b` alkuun.

Taulukon käsittely sen rajojen ulkopuolella on erittäin yleinen syy siihen, että C-ohjelma ei toimi oikealla tavalla. Tämä on kuitenkin tietoinen päätös C-kielen suunnittelussa: ohjelman suoritukseen tuo tehokkuutta se, että ei tarvitse valvoa, onko käytetty indeksi taulukon sisällä.

<div class="note" markdown="1">
C-kielen taulukko näyttää päältä päin melko samanlaiselta kuin Python-kielen lista, mutta näissä tietorakenteissa on suuria eroja:

- C-kielen taulukon koko tulee päättää määrittelyssä eikä kokoa voi muuttaa myöhemmin, kun taas Pythonin listan kokoa voi muuttaa joustavasti.

- C-kielen taulukossa jokaisen alkion tyypin tulee olla sama, kun taas Pythonissa listalle voi lisätä sekalaisen tyyppisiä alkioita.

- Taulukon koon selvittäminen on hankalaa C-kielessä, kun taas Pythonissa koon voi selvittää helposti `len`-funktiolla.

- C-ohjelman suorituksen aikana taulukon rajoja ei valvota, kun taas Pythonissa viittaus taulukon rajojen ulkopuolelle aiheuttaa virheen.

Näiden erojen taustalla on jälleen, että Pythonin lista on pinnan alla huomattavasti monimutkaisempi tietorakenne kuin C-kielen taulukko. Myöhemmin selviää, miten voimme tehdä itse C:llä jotain vastaavaa.
</div>

### Taulukko muistissa

Taulukon alkiot tallennetaan peräkkäin muistissa, minkä ansiosta minkä tahansa taulukon alkion muistiosoitteen pystyy laskemaan tietämällä taulukon ensimmäisen alkion muistiosoitteen.

Aiemmin opitun perusteella looginen syntaksi selvittää taulukon `array` ensimmäisen alkion muistiosoite olisi `&array[0]` ja tämä onkin toimiva syntaksi. Kuitenkin myös lyhyempi syntaksi `array` antaa ensimmäisen alkion muistiosoitteen. Seuraavassa koodissa molemmat rivit tulostavat saman muistiosoitteen.

```c
printf("%p\n", &array[0]);
printf("%p\n", array);
```

Voikin ajatella, että merkintä `array` tarkoittaa myös osoitinta, joka osoittaa taulukon `array` ensimmäiseen alkioon. Yleisemmin `array + i` on muistiosoite taulukon alkioon indeksissä `i` ja syntaksin `array[i]` voi ajatella olevan lyhennysmerkintä osoitinta käyttävälle syntaksille `*(array + i)`.

Seuraava koodi havainnollistaa asiaa:

```c
int array[] = {3, 1, 4, 1, 5, 9, 2, 6};
for (int i = 0; i < 8; i++) {
    printf("%d ", *(array + i));
}
printf("\n");
```

Koodin tuloksena on:

```
3 1 4 1 5 9 2 6
```

Huomaa, että syntaksi `array + i` tarkoittaa, että muistiosoitetta kasvatetaan `i` kertaa taulukon alkion koolla. Esimerkiksi jos taulukko sisältää `int`-lukuja ja `int`-tyypin koko on 4 tavua, jokainen lisäys kasvattaa muistiosoitetta 4:llä. Tämä on hyödyllinen ominaisuus, koska se helpottaa taulukon alkioihin viittaamista.

Seuraava koodi havainnollistaa asiaa:

```c
int numbers[] = {3, 1, 4, 1, 5, 9, 2, 6};
for (int i = 0; i < 4; i++) {
    printf("%p\n", numbers + i);
}
```

Koodin tulostus on seuraava:

```
0x7ffc9a014930
0x7ffc9a014934
0x7ffc9a014938
0x7ffc9a01493c
```

Tästä näkee, että jokaisen muistiosoitteen erona on 4 tavua.
